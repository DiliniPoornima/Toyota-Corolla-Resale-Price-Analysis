Statistical analysis and multiple linear regression modeling of used Toyota Corolla resale prices using R, including exploratory data analysis, hypothesis testing, regression diagnostics, and model selection.
# Toyota Corolla Resale Price Analysis Using Multiple Linear Regression

## Project Overview
This project investigates the impact of vehicle attributes on the resale prices of used Toyota Corolla cars using statistical analysis and Multiple Linear Regression (MLR) in R.

The main objective is to identify the key factors influencing used car prices and develop an interpretable regression model.

## Dataset
- **Source:** Kaggle – Used Toyota Corolla Cars
- **Observations:** 248
- **Target Variable:** Resale Price
- **Predictor Variables:** Age, Mileage (KM), Color, Engine Capacity (CC), and Weight

Dataset source: https://www.kaggle.com/datasets/vishakhdapat/price-of-used-toyota-corolla-cars

## Tools and Technologies
- R Programming
- RStudio
- Statistical Analysis
- Data Visualization

## Methodology
1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Correlation Analysis
4. Multiple Linear Regression
5. Regression Assumption Checking
6. Hypothesis Testing and ANOVA
7. Variable Selection and Model Comparison

## Key Results
- Full Model R²: **89.29%**
- Reduced Model R²: **87.66%**
- Vehicle age and mileage showed negative relationships with resale prices.
- Vehicle weight showed a positive relationship with resale prices.
- The full regression model was selected as the more suitable model based on the statistical comparisons.

## Conclusion
The study demonstrated how multiple linear regression can be used to analyze the relationships between vehicle characteristics and resale prices. The findings provide useful insights into the factors associated with used Toyota Corolla car valuations.
